# Introduction

「采词」意为采集阅读中的词汇，「Collex」源自 Collect（收集）与 Lexis（词汇）的结合，象征高效的语言积累。

"采词" means harvesting words from texts, while "Collex" blends Collect + Lexis, embodying smart language accumulation.
